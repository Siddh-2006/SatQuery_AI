# server/serve.py -- the EOCaptioner offline model server. This file didn't
# exist before (the script was run ad hoc against a global Python install);
# added so it can be containerized (see Dockerfile) and set up in one
# `pip install`.
#
# Python: 3.13 (tested on 3.13.7 -- see ../.python-version). Pins below
# match what was already installed in this project's global Python
# environment (torch/transformers/numpy/rasterio/fastapi/etc. were already
# there from earlier training/serving work) -- if you're setting this up
# fresh elsewhere, these are still a known-good, mutually compatible set.
#
# NOTE on venvs + torch: the model files being local/offline does NOT mean
# the `torch` *library* is optional -- PyTorch is the runtime that actually
# executes the model's tensor ops, regardless of whether the weights came
# from the internet or a local .pth file. If you create a fresh venv for
# this folder, either accept the (large, one-time) download, or create it
# with `python -m venv --system-site-packages .venv` to reuse an existing
# global install instead of re-downloading -- that's what this project's
# own server/.venv does.
